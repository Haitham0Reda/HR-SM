# License Server API Documentation

## Overview

The License Server provides a REST API for managing tenant metadata, subscriptions, and module configurations. This API serves as the single source of truth for platform control data, separating it from business operations data.

**Base URL:** `http://localhost:4000` (development) / `https://license.yourdomain.com` (production)

**API Version:** v1

**Protocol:** HTTPS (required in production)

---

## Authentication

All API requests require authentication using API keys.

### API Key Authentication

Include the API key in the request header:

```http
X-API-Key: your-api-key-here
```

### Obtaining API Keys

API keys are generated by system administrators:

```bash
node hrsm-license-server/src/scripts/generateApiKey.js --name "Main Backend" --permissions "tenants:read,tenants:write"
```

### Authentication Errors

**401 Unauthorized** - Missing or invalid API key

```json
{
  "success": false,
  "error": {
    "code": "AUTHENTICATION_FAILED",
    "message": "Invalid or missing API key",
    "statusCode": 401
  }
}
```

**403 Forbidden** - Insufficient permissions

```json
{
  "success": false,
  "error": {
    "code": "INSUFFICIENT_PERMISSIONS",
    "message": "API key does not have permission to perform this operation",
    "requiredPermission": "tenants:write",
    "statusCode": 403
  }
}
```

## Tenant Management Endpoints

### List All Tenants

Retrieve a paginated list of all tenants.

**Endpoint:** `GET /api/tenants`

**Required Permission:** `tenants:read`

**Query Parameters:**

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| page | integer | 1 | Page number |
| limit | integer | 50 | Items per page (max: 100) |
| status | string | - | Filter by status: `active`, `suspended`, `deleted` |
| sort | string | `createdAt` | Sort field |

```bash
curl -X GET "http://localhost:4000/api/tenants?page=1&limit=10&status=active" \
```

## Error Responses

### Standard Error Format

All error responses follow this format:

```json
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "Human-readable error message",
    "details": {},
    "statusCode": 400
  }
}
```

### Common Error Codes

| Code | Status | Description |
|------|--------|-------------|
| `AUTHENTICATION_FAILED` | 401 | Invalid or missing API key |
| `INSUFFICIENT_PERMISSIONS` | 403 | API key lacks required permissions |
| `TENANT_NOT_FOUND` | 404 | Tenant does not exist |
| `TENANT_ALREADY_EXISTS` | 409 | Tenant ID already in use |
| `VALIDATION_ERROR` | 400 | Invalid request data |
| `MODULE_NOT_FOUND` | 404 | Module does not exist |
| `SUBSCRIPTION_NOT_FOUND` | 404 | Subscription does not exist |
| `INTERNAL_SERVER_ERROR` | 500 | Unexpected server error |
| `SERVICE_UNAVAILABLE` | 503 | Service temporarily unavailable |

## Rate Limiting

API requests are rate-limited to prevent abuse.

**Limits:**
- 1000 requests per hour per API key
- 100 requests per minute per API key

**Rate Limit Headers:**

```http
X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 987
X-RateLimit-Reset: 1643299200
```


## SDK Examples

### JavaScript/Node.js

```javascript
const axios = require('axios');

class LicenseServerClient {
  constructor(baseUrl, apiKey) {
    this.client = axios.create({
      baseURL: baseUrl,
      headers: {
        'X-API-Key': apiKey,
        'Content-Type': 'application/json'
      }
    });
  }

  async getTenant(tenantId) {
    const response = await this.client.get(`/api/tenants/${tenantId}`);
    return response.data.data;
  }

  async getEnabledModules(tenantId) {
    const response = await this.client.get(`/api/tenants/${tenantId}/modules`);
    return response.data.data.modules;
  }

  async enableModule(tenantId, moduleId) {
    const response = await this.client.post(
      `/api/tenants/${tenantId}/modules/${moduleId}`
    );
    return response.data.data;
  }
}

// Usage
const client = new LicenseServerClient(
  'http://localhost:4000',
  'your-api-key'
);

const tenant = await client.getTenant('techcorp_solutions');
console.log(tenant);
```

### Python

```python
import requests

class LicenseServerClient:
    def __init__(self, base_url, api_key):
        self.base_url = base_url
        self.headers = {
            'X-API-Key': api_key,
            'Content-Type': 'application/json'
        }
    
    def get_tenant(self, tenant_id):
        response = requests.get(
            f'{self.base_url}/api/tenants/{tenant_id}',
            headers=self.headers
        )
        response.raise_for_status()
        return response.json()['data']
    
    def get_enabled_modules(self, tenant_id):
        response = requests.get(
            f'{self.base_url}/api/tenants/{tenant_id}/modules',
            headers=self.headers
        )
        response.raise_for_status()
        return response.json()['data']['modules']

# Usage
client = LicenseServerClient('http://localhost:4000', 'your-api-key')
tenant = client.get_tenant('techcorp_solutions')
print(tenant)
```
